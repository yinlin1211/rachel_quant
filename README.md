# rachel_quant

L2 逐笔行情上的因子计算流水线。核心思路：**tick 只读一次，落成分钟面板；之后所有因子实验只读面板。**

当前状态：Alpha101 82 条因子在 10 个交易日上跑通，计算阶段 **30 秒**。

## 目录

```
.
├── DEVELOPMENT.md        # 研发链路 / 迭代记录（每次更新都追加）
├── pipeline/             # 当前最快链路
│   ├── README.md         # 架构、格式、实测性能、限制
│   ├── build.sh
│   ├── run_pipeline.sh
│   ├── src/              # C++：面板生成 + 82 条公式
│   └── tools/            # Python：IC 汇总 / 交叉验证
├── results/              # 小体积结果（IC 表、统计量）
├── cpp_alpha/            # 第 1 代原型：手写 5 因子 + cache/compute 两级设计
└── scripts/              # 第 0 代 Python 基准脚本
```

## 快速开始

```bash
cd pipeline
./build.sh
./run_pipeline.sh 20260105 20260116 out_10d 2
```

依赖：GCC（C++11）、OpenMP、`liblf_tick2py.so`（平台提供的 tick 读取库）。
数据路径固定为 `/opt/bar_data`。

## 关键数字

| 项目 | 数值 |
|---|---|
| 原始数据 | 23.9 GB/天，4.37 亿条 tick |
| 分钟面板 | 60 MB/天，125 万行（压缩 400 倍） |
| 建面板 | 50 s（热）～ 500 s（冷，机械盘） |
| 82 因子计算 | 11.8 s（32 线程，10 天） |
| 端到端（面板已就绪） | 30 s / 10 天 |
| 磁盘上限 | ~240 MB/s，1–2 路并发即可打满 |

## 数据说明

原始 tick、面板、因子 `.dat` **不在仓库里**（体积大且可重建）。
仓库只保留代码、文档和小体积的 IC 结果。
