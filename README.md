# rachel_quant

L2 逐笔行情上的因子计算流水线。核心思路：**tick 只读一次，落成分钟面板；之后所有因子实验只读面板。**

当前状态：Alpha101 82 条因子在 10 个交易日上跑通，计算阶段 **30 秒**。

---

## 我们在研究什么样的因子

### 一句话

**每分钟，给全市场每只股票算一个分数，看这个分数能不能预测它未来 1 分钟的涨跌。**

### 因子是什么

因子就是一个**能排序的数**。假设 10:00 这一刻，我们给 5213 只股票各算一个数：

| 股票 | 因子值 | 按因子排序 | 实际未来 1 分钟收益 |
|---|---|---|---|
| A | 0.82 | 第 1 名 | +0.03% |
| B | 0.51 | 第 2 名 | +0.01% |
| … | … | … | … |
| Z | 0.03 | 最后一名 | -0.02% |

如果"排在前面的股票，未来确实涨得更好"，这个数就是有效因子。

**我们的任务是：找到、验证、筛选这样的数。**

### 具体在研究什么

| 维度 | 我们的设定 |
|---|---|
| **频率** | 每分钟一次（一天 240 个截面） |
| **范围** | 全市场 5213 只股票（截面因子，不是单只股票的时间序列） |
| **输入** | L2 逐笔行情聚合出的分钟 OHLC、成交量、成交额、vwap |
| **预测目标** | 未来 1 / 3 / 5 分钟的价格收益（基点） |
| **样本量** | 每天 240 × 5213 ≈ **125 万个观测**，10 天 = 1250 万 |

### 因子从哪来：Alpha101

WorldQuant 在 2015 年公开的 **101 个公式化因子**，全部由价量数据构成。举两个例子：

```python
alpha101 = (close - open) / (high - low + 0.001)
# 含义：这一分钟 K 线"实体"占"振幅"的比例。
# 实体大 = 单边推进；实体小 = 上下影线多、多空拉锯。

alpha004 = -1 * ts_rank(rank(low), 9)
# 含义：当前最低价在最近 9 分钟里的相对位置，再在全市场排名。
# 抓的是"短期超跌"。
```

这些公式**不含任何基本面数据**，只用价格和成交量——这正是它能跑在 L2 逐笔数据上的原因。

### 我们对原版做的改造

原版 Alpha101 是**日线**因子（窗口 20 = 20 天）。我们把它搬到**分钟线**：

| | 原版 | 我们 |
|---|---|---|
| 一根 bar | 1 天 | 1 分钟 |
| 窗口 20 | 20 天 | 20 分钟 |
| 价格 | 收盘价 | 中间价 (买一+卖一)/2 |
| 数据 | 日线 OHLCV | 从 4.37 亿条 tick 聚合 |

这意味着因子含义变了：从"月度动量"变成"分钟级微观结构"，是**另一类信号**，需要重新验证。

### 怎么判断一个因子好不好

核心指标是 **IC（信息系数）**：因子值与未来收益的相关系数。

```
IC = corr(这一分钟的因子值, 这一分钟之后 1 分钟的收益)
```

| 指标 | 含义 | 参考 |
|---|---|---|
| **IC 均值** | 平均预测力 | 分钟级 0.02 已算不错；0.05 以上很难得 |
| **IC 标准差** | 每天 IC 的波动 | 越小越稳 |
| **IR** = IC均值/IC标准差 | 稳定性 | > 2 比较可靠 |
| **IC>0 占比** | 方向是否一致 | 100% = 10 天全部同向 |

举例，我们 10 天的结果：

```
alpha004   IC = 0.0214   IR = 4.55   IC>0 占比 100%
```

读作：**这个因子平均每天和未来 1 分钟收益正相关 0.0214，10 天里 10 天都是正的，而且每天的值很稳定。**

### 因子最终拿来干什么

1. **单因子**：看 IC，判断有没有预测力；
2. **多因子**：把 82 个因子值一起喂给 LightGBM，训练一个分钟级收益预测模型；
3. **组合**：预测值排序，选头部股票做多 / 尾部做空。

### 我们现在的进度

| 阶段 | 状态 |
|---|---|
| 管线跑通（tick → 面板 → 因子 → IC） | ✅ 10 天，30 秒 |
| 82 条公式实现 | ✅ 能算、格式正确 |
| **数值正确性验证** | ❌ **未做**（最大风险） |
| 样本长度 | ⚠️ 10 天，只够验证管线，不够选因子 |
| 目标 | 3 个月 → 1 年，再谈因子选型 |

> **重要**：现在表里的 IC 数字只能说明"管线是通的"，不能说明"因子有效"。10 个样本日太短，任何排名都可能是噪音。真正的结论要等样本拉长 + 公式校验完成。

## 快速开始

```bash
cd pipeline
./build.sh
./run_pipeline.sh 20260105 20260116 out_10d 2
```

依赖：GCC（C++11）、OpenMP、`liblf_tick2py.so`（平台提供的 tick 读取库）。
数据路径固定为 `/opt/bar_data`。
